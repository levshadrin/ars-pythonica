Introduction

Ars Pythonica offers an introduction to programming in Python aimed at classical philologists who work with Greek and Latin texts and seek to incorporate digital humanities and distant reading methods into their research. No prior programming experience is required.

By the end, you should be able to read and write code and understand what it does, find and fix errors, be familiar with the fundamentals of Python syntax, apply basic pre-processing, data extraction, and data normalization methods, perform exploratory data analysis, and take first steps in using distant reading tools on your own textual corpora.

How the course works

This book is a supplement to twelve weekly sessions of 90 minutes, plus an optional final hackathon-style session, during which we will aim to create, clean up, and structure your research corpora.

The course is structured as a flipped classroom: you learn the concepts at home via interactive courses, while in the session we do a quick recap, address challenges and issues, and then apply the newly acquired skills together to Greek and Latin texts.

  • At home:
    • in Part I, assignments from futurecoder and Exercism, up to the checkpoint given in the schedule;
    • in Part II, TBA.
  • In the session: a quick concept check, troubleshooting, hands-on workshop (e.g. installation, IDE setup, Jupyter notebooks, CLI, data extraction, corpus cleanup etc.), debugging, and results review.

Every session is still useful if you didn’t manage the home assignments, but it is nevertheless recommended to complete the basic exercises, since coding is a practical skill.

Using AI

TipGeneral practice

You can use AI to explain, not to code.

The aim of this course is not to produce impeccable coding solutions to problems, rather to allow participants to break code and experience as many errors as possible through practice and active debugging.

Therefore, the use of AI is allowed on an honor system. To make it practical, feel free to use this tutor prompt or set it as custom instructions if you decide to use AI:

I'm learning Python. Explain concepts and error messages, and ask me guiding questions. Don't give me the solution right away, don't write or fix code for me.
